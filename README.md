# Cisco IDS/IPS Configuration

## Overview

Implementation and validation of network security controls using Cisco Packet Tracer, with a focus on traffic inspection, intrusion detection, intrusion prevention, and network access control.

## Network Environment

The initial topology consists of:

- 2 × Cisco 2911 routers
- 2 × Cisco 2960-24TT switches
- 4 × PCs
- 2 × Server-PT devices

## Implementation Scope

- Configure router interfaces and IP addressing.
- Establish routing between network segments.
- Validate connectivity and packet flow.
- Implement and test supported network security controls.
- Investigate IDS alerting and IPS traffic-blocking behaviour.
- Record CLI configurations, verification output, screenshots, and test results.

## Configuration and Evidence

Device configurations, implementation records, network diagrams, and verification evidence will be added as each stage is completed.

All results will reflect actual testing. Features that Cisco Packet Tracer does not support will be identified rather than represented as implemented.
